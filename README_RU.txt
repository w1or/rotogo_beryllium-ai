ROTOGO BERYLLIUM v7.1 — ГЛАВНОЕ
=================================
(раньше проект назывался «Локальный Ассистент»)

Офлайн-помощник для Windows на одном файле Python (без библиотек).
Открывает программы и сайты, ищет в Google, показывает погоду и курсы
валют прямо в чате, считает примеры, ставит таймеры, переводит, создаёт
папки, документы .txt/.docx, настоящие презентации .pptx и таблицы .xlsx,
ведёт заметки, ищет файлы.

ЧТО НОВОГО В v7.1 — ДВА ЯЗЫКА В ОДНОМ ПРИЛОЖЕНИИ
  - Переключатель интерфейса Русский / English прямо в окне:
    кнопка «RU»/«EN» в правом верхнем углу шапки ИЛИ команда
    «язык» / «english» / «russian» / «language».
  - Выбор языка сохраняется в файл lang.txt и применяется при следующем
    запуске. По умолчанию — русский.
  - Команды понимаются на обоих языках: можно написать «погода» или
    «weather», «открой блокнот» или «open notepad».
  - В английском режиме Википедия берётся из en.wikipedia.org, а промпты
    Gemini и текст слайдов/документов генерируются на английском.

МИНИ-ПРИЛОЖЕНИЯ ПРЯМО В ЧАТЕ
  1. ПОГОДА: «погода» / «погода в москве» (weather / weather in moscow) —
     температура, ощущается, ветер, влажность, минимум-максимум дня
     (wttr.in + Open-Meteo, без ключей). Сбой сети — откроется сайт.
  2. КУРС ВАЛЮТ: «курс» / «курс доллара» (rates / rates usd) — свежие
     курсы ЦБ РФ с изменением за день (▲/▼). Кэш на 10 минут.
  3. КАЛЬКУЛЯТОР: «посчитай 2+2*10», «сколько будет 15% от 200»,
     «calculate 2+2*10», «how much is 15% of 200», «2^10», скобки,
     остаток %. Безопасно: без eval.
  4. ТАЙМЕР: «таймер на 5 минут», «напомни через 30 секунд»
     (timer for 5 minutes) — окно, пузырь в чате и звук.
  5. ПЕРЕВОД: «переведи hello world» (translate hello world) — Gemini
     (если есть ключ) или Google Переводчик в браузере.
  6. ТАБЛИЦЫ EXCEL: «создай таблицу про X» (make a spreadsheet about X) —
     настоящий .xlsx: шапка с заливкой и закреплена, автофильтр, ширины
     колонок, разрядка тысяч у чисел.
  7. ПОИСК ФАЙЛОВ: «найди файл отчет» (find file report) — поиск по
     рабочему столу, документам и загрузкам; свежие сверху.
  8. МОНЕТКА И КУБИК: «монетка», «кубик» (coin / dice).

ВИЗУАЛ
  - тёмный титул окна в стиле Windows 11 + собственный значок «RB»;
  - два ряда быстрых команд-чипов (8 штук, меняются по языку);
  - пузыри плавно «всплывают»; прогресс в одном пузыре;
  - правая кнопка мыши на сообщении копирует его текст;
  - история команд стрелками вверх/вниз; часы в шапке.

ФАЙЛЫ ПРОЕКТА
  rotogo.pyw     — сама программа (один файл, без библиотек)
  start.bat      — запуск без консоли (двойной клик)
  gemini_key.txt — API-ключ Gemini (НЕТ В КОМПЛЕТЕ; создаётся вами,
                   см. ниже; опционален)
  lang.txt       — выбранный язык интерфейса (создаётся программой)
  README_RU.txt  — этот файл
  README_EN.txt  — краткое описание на английском

КАК ЗАПУСКАТЬ
-------------
Требуется Python 3.8+ (python.org). Библиотеки ставить НЕ нужно.

    Способ 1 (рекомендуется): двойной клик по start.bat
    Способ 2: двойной клик по rotogo.pyw (через pythonw)
    Способ 3: в командной строке  python rotogo.pyw

КЛЮЧ GEMINI — ОПЦИОНАЛЕН
------------------------
Приложение полностью работает БЕЗ ключа: текст для презентаций, документов
и таблиц берётся из Википедии и встроенной базы знаний, погода и курсы —
из открытых источников. Ключ нужен только если хотите, чтобы текст
писал Google Gemini (серия flash) и чтобы ассистент понимал совсем
нестандартные формулировки.

    Как подключить (бесплатно):
      1. aistudio.google.com → кнопка «Get API key» (начинается с AIza
         или AQ.).
      2. Внутри приложения напишите «подключи гугл» (connect google) и
         вставьте ключ, ИЛИ «ключ из файла» (key from file) и выберите
         txt-файл с ключом.
      3. Ключ сохраняется в gemini_key.txt рядом с программой и НИКУДА
         с компьютера не уходит.

    ВАЖНО для GitHub: НЕ коммитьте gemini_key.txt — он в .gitignore.
    В этой сборке ключа НЕТ.

ОСНОВНЫЕ КОМАНДЫ (внутри приложения напишите «помощь» / «help»)
  погода [в городе] / weather [in city]      погода в чате
  курс [доллара|евро|юаня] / rates           курсы ЦБ РФ
  посчитай 2+2*10 / calculate 2+2*10         калькулятор
  таймер на 5 минут / timer for 5 minutes    напомню звуком и окном
  переведи <текст> / translate <text>        Gemini или Google Переводчик
  монетка / кубик / coin / dice              случайность
  загугли <запрос> / google <query>          поиск в Google
  открой <приложение/сайт> / open <app/site> блокнот, роблокс, стим, ютуб…
  создай папку <имя> / create folder <name>  [на рабочем столе / в документах]
  создай текстовый документ про X            .txt с настоящим текстом
  создай документ (ворд) про X               .docx для Word
  создай презентацию про X                   .pptx с фото и фактами;
    make a presentation about X              можно «в папку <имя>» и «на 10 слайдов»
  создай таблицу про X / make spreadsheet    .xlsx (Excel) с оформлением
  запиши заметку <текст> / take a note       .txt-файл на рабочем столе
  найди файл <имя> / find file <name>        поиск в столе/документах/загрузках
  подключи гугл / connect google             вставить API-ключ Gemini
  ключ из файла / key from file              выбрать txt-файл с ключом
  удали ключ / remove key                    забыть ключ
  время / дата / характеристики              время, дата, характеристики ПК
  язык / english / russian / language        переключить язык интерфейса
  очисти чат / clear chat                    очистка истории
  пока / bye                                 выход

Пишите как удобно — сокращения, разговорные варианты и опечатки
поддерживаются. Стрелки вверх/вниз — история команд. Правая кнопка на
сообщении — копировать.

ОТКУДА БЕРЁТСЯ ТЕКСТ (по очереди, что раньше сработает):
  а) Google Gemini (серия flash) — если подключён ключ;
  б) Википедия — реальные факты и фотографии, ключи не нужны;
  в) встроенная база знаний — работает без интернета.
Источник честно указывается в ответе и на финальном слайде. Фото — из
Википедии, Wikimedia Commons, Openverse, Flickr (без ключей); генерации
изображений через API нет — только настоящие снимки.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  - Не открылась программа — откройте error_log.txt рядом с ней.
  - Журнал работы — rotogo.log (откройте блокнотом).
  - «Google отклонил запрос из этой сети» — Gemini API не работает через
    эту сеть/VPN. Смените сеть; Википедия, погода, курсы и офлайн-база
    продолжат работать.
  - «лимит запросов Gemini исчерпан» — у бесплатного ключа кончилась
    квота: подождите минуту и повторите.
  - «Python not found» при запуске start.bat — установите Python с
    python.org и отметьте «Add python.exe to PATH».
